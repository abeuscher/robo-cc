# Session 001 — Arena & BUILD phase — Log

**Date:** 2026-09-03
**Branch:** session-001 (worked on local branch `session-001/1`)
**Roadmap section:** Pass 0 (skeleton, folded in) + Pass 1 — BUILD phase, end to end

## What was built

Open questions from the brief were settled at the Open Gate: (1) keep the title screen /
`StartRequested` as the entry, (2) solo-permissive test — one player is the Builder and the
BUILD loop stays usable, (3) the build grid is a **vertical plane** (`Vector2` = column,
row), one block per plane cell.

### Phase 1 — Shared foundation

- Created `src/shared/Config.luau` with the full tunable set: block dims / mass / friction /
  restitution, block count, Princess distance, gap width, ballista + catapult constants,
  shots per turn, rounds per match, plus `GridSize`, `BuildZoneSize`, `BuildZoneOrigin`,
  `MovingBlockKillSpeed`, `ProjectileLifetime`, `CatapultImpact`, and arena-geometry
  constants (`PlatformSize`, `PrincessSize`, `GroundLevel`).
- Created `src/shared/Types.luau` — `Phase`, `Role`, `Weapon`, `ShotPayload`, `Roles`,
  `StatePayload` (later `PlacePayload`, `BlockType`, `BlocksRemaining`).
- Created `src/shared/GridUtil.luau` — world ⇄ cell, `snapToWorld`, `isInside`,
  `columns` / `rows` (later `spanForSize`, `coveredCells`, `footprintCentre`).
- Extended `src/shared/Remotes.luau` with `PlaceBlock`, `PickupBlock`, `ConfirmBuild`,
  `StateChanged`. Deleted `src/shared/Hello.luau`.

### Phase 2 — Arena & Princess (server)

- Created `src/server/Arena.luau` — `build()` draws Builder platform, Attacker platform, a
  translucent build-zone marker, a firing-position pad, and the `Princess` part into
  `Workspace.ActiveRound`. `reset()` clears the folder; `root()` exposes it. Plain grey
  parts, blue markers.

### Phase 3 — State machine & roles (server)

- Created `src/server/MatchController.luau` — join-order roster, Builder/Attacker
  assignment, character positioning onto the platforms (`standFor` / `CharacterAdded`),
  `StateChanged` broadcasts, `confirmBuild` → `phase = "ATTACK"` + broadcast + hold.
  Solo-permissive; no hard 2-player gate. Re-broadcasts on `StartRequested` so a client
  that connected late still gets current state.
- Rewrote `src/server/init.server.luau` to `Arena.build()` → `MatchController.start()` →
  `BuildManager.start()` (later `BlockManager.spawnAll()` inserted).

### Phase 4 — Block placement (server + client)

- Created `src/server/BlockManager.luau` — anchored block `Part`s with `PhysicalProperties`
  from `Config`, `BlockId` attribute, budget tracking.
- Created `src/server/BuildManager.luau` — `PlaceBlock` / `PickupBlock` / `ConfirmBuild`
  handlers, each re-validating role + phase + limits; authoritative grid occupancy keyed by
  `"col,row"`.
- Created `src/client/BuildInput.luau` — mouse-ray → vertical-plane intersection → snapped
  translucent ghost; click to place, click a block to pick up, on-screen **Confirm Wall**
  button. Active only for the Builder during BUILD.

### Phase 5 — HUD

- Created `src/client/Hud.luau` — role banner, phase label, blocks-remaining, "waiting for
  the other player" line. Driven by `StateChanged`.
- Wired `src/client/init.client.luau` to buffer `StateChanged` and hand off from the title
  screen to `Hud` + `BuildInput` on Start.

### Post-gate additions (in-session, at the user's request)

- **Camera intro** — created `src/client/CameraIntro.luau`: overhead shot pinned above the
  local player while the title screen is up, then a `TweenService` swoop into the play
  camera on Start (`Back` easing; the user was still tuning `RELEASE_UP` / `TWEEN_TIME` /
  easing direction at close). Wired into `init.client.luau`.
- **Doc comments** — added a description comment above every function in `BuildInput.luau`.
- **Multi-shape block system** (largest change — see Config changes and Deferred).
  Decisions taken via a question round: click-to-lift then click-to-place; the Wide block
  is rotatable (`R`); the Wide block is 3× mass at equal density.
  - `Config.BlockTypes` — array of `{ Name, Size, Count, Rotatable, PileOrigin }`. Standard
    `2.5×1.25×2.5 ×6`; Wide `7.5×1.25×2.5 ×6`, rotatable. `PlatformSize.X` widened
    `40 → 56` to fit both piles on the builder's right.
  - `BlockManager` rewritten to `spawnAll()` at match start — every block is a persistent
    anchored `Part` (attributes `BlockId` / `BlockType` / `Placed`) in its pile; one
    density for all, so Wide masses 3×. `moveToWall` / `returnToPile` reposition the same
    Part. `remainingByType()`.
  - `BuildManager` — `PlaceBlock` payload is `{ blockId, cell, rotated }`; multi-cell
    footprint (`GridUtil.spanForSize` → Wide is 3×1 flat, 1×6 rotated), all covered cells
    validated in-bounds and free.
  - `BuildInput` — held-block model; the lifted Part hides on the local client via
    `LocalTransparencyModifier`; `R` rotates (Wide only), `Q` drops, empty-handed click on
    a placed block returns it to its pile.
  - `MatchController.blocksRemaining` and `StateChanged` became `{ Standard, Wide }`;
    `Hud` shows two counters plus a one-line controls hint for the Builder.
  - `Arena` draws a faint pad under each pile.

## Playtest result

Playtested by the user in Studio (the agent environment can't run Studio). Two-player
BUILD-phase runs: role assignment and banners correct, characters spawn on their platforms,
Builder lifts blocks from both piles, places on the vertical grid, rotates the Wide block,
rearranges, and confirms; HUD flips to ATTACK and the input tears down. Camera intro plays
on Start. User reported it "green" and "looking good" with no outstanding issues. The
lift-hides-block tweak was verified after it was added. `rojo build` (rojo 7.7.0, the only
tool in `rokit.toml`) was run after every file change as a structural sanity check — no
lint/type tooling is installed.

## Config changes

`src/shared/Config.luau` was created this session, so every constant is new. Drift from the
brief and mid-session retunes:

- `GridSize` — a `Vector2(2.5, 1.25)` (column pitch, row pitch), not a scalar; the vertical
  grid isn't square.
- `BuildZoneSize` — `Vector2(20, 10)` studs → 8 columns × 8 rows.
- `BuildZoneOrigin.Z` — `GapWidth/2 + BlockSize.Z/2` so the wall's front face sits on the
  gap edge.
- `PlatformSize` — `Vector3(40, 1, 30)` → **`Vector3(56, 1, 30)`** to fit the two piles.
- `BlockTypes` — added (Standard ×6, Wide ×6); `BlockCount` (12) kept as the informational
  total.
- Added arena-geometry constants (`PlatformSize`, `PrincessSize`, `GroundLevel`) and pile
  origins (inside `BlockTypes`).
- First-pass values unchanged and untuned: `PrincessDistance = 14`, `GapWidth = 40`,
  ballista/catapult constants, `ShotsPerTurn = 6`, `RoundsPerMatch = 4`,
  `MovingBlockKillSpeed = 10`, `ProjectileLifetime = 5`, `CatapultImpact = 60`,
  `BlockMass = 25`, `BlockFriction = 0.5`, `BlockRestitution = 0.1`.
